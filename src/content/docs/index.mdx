## Security Is Free. Scale & Compliance Are Enterprise.

<CardGrid stagger>
  <Card title="🛡️ Zero SSO Tax (MIT Core)" icon="approve-check">
    Argon2id + legacy bcrypt auto-upgrade, keyed BLAKE3 session digests, TOTP MFA, Passkeys/WebAuthn, API keys, CSRF & origin guards, RBAC, and transactional audit trails are **100% free and MIT-licensed**.
  </Card>
  <Card title="🧩 Embed Like Better Auth — In Rust" icon="puzzle">
    Do not want a separate auth service? Drop `vaelspire-auth`, `vaelspire-axum`, and `vaelspire-store-sqlite` or `vaelspire-store-postgres` directly into your Rust binary over `neotales-dbapi`.
  </Card>
  <Card title="⚡ Single Binary + /forward-auth" icon="rocket">
    Run one `#![forbid(unsafe_code)]` Rust binary with embedded SQLite and protect **Vaelsgard** or any HTTP backend in 3 lines of Caddy, Traefik, or Nginx config.
  </Card>
  <Card title="🏢 Built to Grow Into Enterprise" icon="setting">
    Upgrade seamlessly when you need **multi-region geo-replication**, **WORM immutable audit storage** (S3 Object Lock / Azure / GCS), **SIEM & OTel telemetry**, seat packs, and **FIPS 140-3**.
  </Card>
</CardGrid>
