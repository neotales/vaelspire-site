## Security Is Free. Scale & Compliance Are Enterprise.

<CardGrid stagger>
  <Card title="🛡️ Zero SSO Tax (MIT Core)" icon="approve-check">
    Argon2id + legacy bcrypt auto-upgrade, TOTP MFA, Passkeys/WebAuthn, **OIDC 1.0 IdP (Ed25519 JWKS + PKCE + Refresh Rotation)**, **SCIM 2.0**, **AI Agent NHI**, RBAC, and `/forward-auth` are **100% free and MIT-licensed**.
  </Card>
  <Card title="🧩 Embed Like Better Auth — In Rust" icon="puzzle">
    Do not want an extra auth service? Embed `vaelspire-auth`, `vaelspire-axum`, `vaelspire-verify`, and SQLite/PostgreSQL stores directly into your Rust binary over `neotales-dbapi`.
  </Card>
  <Card title="⚡ Single Binary + Embedded Web UI" icon="rocket">
    Compile `--features embed-ui` for one fast `#![forbid(unsafe_code)]` Rust binary with built-in Login, OIDC Consent, Account/API Keys, and Admin Console — or switch to `--ui-mode external` for Enterprise CDNs.
  </Card>
  <Card title="🏢 Isolated Enterprise Modules" icon="setting">
    Upgrade seamlessly via `vaelspire-core::extensions` when you need **EU/US/APAC geo-replication**, **hash-chained WORM storage** (S3 Object Lock / Azure / GCS), **OTLP/Splunk/Datadog SIEM**, and **never-brick-logins** offline Ed25519 licensing.
  </Card>
</CardGrid>
